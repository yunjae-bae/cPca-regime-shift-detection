# cPCA-based Multivariate Time-Series Regime Shift Detection

An exploratory study of multivariate structural change using FRED macroeconomic series.

## Research overview

Compare background and target covariance with cPCA, then combine variance ratios and principal-component directions in a Dual-State Structural Index (DSSI) for sequential change detection.

## Data

Six macroeconomic series from FRED (Federal Reserve Economic Data).
- Economic activity: INDPRO, RSAFS, PCE
- Employment and prices: UNRATE, CPIAUCSL
- Financial markets: DGS10

## Data

Use six macroeconomic CSV series downloaded from FRED.

Find the following six series on [FRED](https://fred.stlouisfed.org), download each CSV,
and place them beside the notebook.

`INDPRO`, `CPIAUCSL`, `RSAFS`, `PCE`, `UNRATE`, `DGS10`
